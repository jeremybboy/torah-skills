# Output Adapters

Use this reference when the user asks for an output other than a full written chapter.

## Shared Rule

Every output must preserve the source chain. The format can change, but the methodology cannot disappear.

## Website Chapter

Use the full 10-step framework. Keep the Markdown structure stable, add a source baseline, and ensure local assets have clear provenance.

## Lesson Plan

Convert the 10-step framework into:

1. Learning objective
2. Source packet
3. Opening question
4. Three to five core sugyot or themes
5. Guided discussion questions
6. Application or reflection
7. Review and source baseline

## Video Script

Convert the chapter into:

1. Hook
2. Peshat setup
3. Core tension
4. Source journey
5. Human application
6. Closing question
7. Source notes for description or credits

Do not script confident claims that are not source-backed.

## Image Brief

Use the methodology to define the concept, not to invent source facts. Include:

- Parashah and verse anchor
- Scene or symbolic focus
- Historical or textual constraints
- Mood
- Elements to avoid
- Source baseline and provenance needs

## Kabbalah or Chassidut Reflection

Keep mystical interpretation separate from peshat. Start with the plain text, then label the mystical or Chassidic move explicitly. Do not present later interpretation as the verse's simple meaning.

## Review Mode

When reviewing an existing artifact, lead with problems:

- Unsourced or overconfident claims
- Blurred source categories
- Weak verse or sugya selection
- Missing major classical sources
- Calendar errors
- Application that does not follow from the text
