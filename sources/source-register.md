# Source Register

This register tracks the source baseline for each pilot chapter. It is not a replacement for checking the chapter footnotes.

## Project Source Position

Most source links currently point to Sefaria. The site is an independent curation and study-companion project: it selects and organizes source clusters according to the stated methodology, while sending readers back to primary and classical texts whenever possible.

Non-Sefaria sources are used when they are better suited for calendar data, artwork provenance, institutional metadata, or other external context.

## Devarim

- Primary text: Deuteronomy 1:1-3:22.
- Calendar anchor: Shabbat Chazon, before Tisha B'Av.
- Core source clusters: Sifrei Devarim, Rashi, Ramban, Sanhedrin 7a-b, Sotah 34b, Taanit 29a, Bava Kamma 38b, Mishneh Torah.
- Chapter illustration: *Moses Views the Promised Land*, engraving by Gerard Jollain from the 1670 *La Saincte Bible*, public domain source record on Wikimedia Commons.

## Vaetchanan

- Primary text: Deuteronomy 3:23-7:11.
- Calendar anchor: Shabbat Nachamu, after Tisha B'Av.
- Core source clusters: Moshe's prayer, Sinai memory, bal tosif, Shabbat, Shema, love of God, right and good.

## Lech-Lecha

- Primary text: Genesis 12:1-17:27.
- Calendar anchor: 13 Cheshvan 5787 / October 24, 2026, checked for Los Angeles against Hebcal.
- Core source clusters: the call of Abram, famine and Egypt, the Covenant between the Pieces, Hagar and divine seeing, brit milah, Rashi, Ramban, Radak, Pirkei Avot 5:3, Nedarim 32a, Mishnah Nedarim 3:11, and Shabbat 132a.
- Original work: *Beneath the Uncounted Stars* is a contemporary responsive piyyut drafted for this chapter; it is not traditional liturgy.

## Vayera

- Primary text: Genesis 18:1-22:24.
- Calendar anchor: 20 Cheshvan 5787 / October 31, 2026, checked for Los Angeles against Hebcal; this is a single parashah with no festival displacement.
- Haftarah traditions: Ashkenazi II Kings 4:1-37; Sephardi II Kings 4:1-23.
- Core source clusters: Abraham's hospitality, justice and Sodom, Sarah's laughter and Isaac's birth, Hagar and Ishmael in the wilderness, the Akedah, Rashi, Ramban, Bava Metzia 86b-87a, Shabbat 127a, Sanhedrin 109a-b, Rosh Hashanah 16a-b, Mishneh Torah, Ezekiel 16:49, and II Kings 4.
- Original work: *At the Entrance of the Tent* is a contemporary responsive piyyut drafted for this chapter; it is not traditional liturgy.
- Review status: AI-assisted draft pending human verification of text, source framing, calendar details, and media selection.

## Verification Standard

Each chapter should identify:

1. Primary Torah verse or passage.
2. Main classical sources.
3. Whether the claim is peshat, midrash, halachah, philosophy, kabbalah, or application.
4. Any uncertainty or disputed interpretation.
5. Whether a calendar claim was checked against a current calendar source.
