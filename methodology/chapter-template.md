# Chapter Template

Every parashah chapter follows this order.

1. Opening Reflection
2. Narrative Overview
3. Five Principal Sugyot
4. Five Key Verses
5. Advanced Interpretation
6. Personal Application
7. Parenting Reflection
8. Dialectical Analysis
9. Cross-Disciplinary Connection
10. Calendar Integration

## Editorial Notes

- Start with orientation before interpretation.
- Identify source category clearly: Torah, Mishnah, Gemara, Midrash, Rishonim, Kabbalah, Chassidut, Halachah.
- Separate peshat from midrash, halachah, mysticism, and personal application.
- Use direct quotations sparingly.
- Do not invent certainty where sources disagree.
- Treat AI output as draft material until human review confirms the source chain.
